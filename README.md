# Apartment Alert & Analytics Dashboard (myhome)

국토교통부 아파트 실거래가 공공 데이터와 카카오 지도 서비스를 연동하여, 사용자가 설정한 관심 조건의 실거래 정보를 Telegram으로 실시간 전달하고, 수집된 데이터를 바탕으로 다차원 통계 분석과 AI 시장 인사이트를 제공하는 통합 아파트 실거래 모니터링 플랫폼입니다.

---

## 🌟 핵심 가치

- **놓치지 않는 실거래 감시**: 원하는 지역, 단지명, 가격대, 면적 조건을 등록해두면 새로운 실거래가 등록되는 즉시 텔레그램으로 알림을 받아볼 수 있습니다.
- **초고속 데이터 탐색**: 지능형 하이브리드 캐시 구조를 통해 과거 실거래 내역은 지연 없이 즉각 로드되며, 최신 거래는 실시간으로 동기화됩니다.
- **풍부한 시각화 분석**: 단순 목록 조회를 넘어 월별 시계열 가격 추이, 평형별/층수별 가격 분포(Box Plot), 단지 간 비교 리포트를 시각적으로 제공합니다.
- **AI 기반 시장 진단**: 최신 실거래 흐름을 바탕으로 Gemini LLM이 단지 동향과 가격 평가 인사이트를 자동으로 생성합니다.
- **모바일 최적화 UX**: 스마트폰(390px)부터 태블릿, 데스크톱까지 언제 어디서나 쾌적하게 이용할 수 있는 모바일 퍼스트 반응형 웹을 지원합니다.

---

## 🚀 주요 기능 (Features)

### 1. 🔔 맞춤형 실거래 감시 & 실시간 Telegram 알림
- **자유로운 감시 규칙 설정**: 특정 시군구/법정동, 아파트 단지명, 거래가격 범위(최소~최대), 전용면적 범위(최소~최대)를 조합하여 무제한으로 감시 조건을 등록할 수 있습니다.
- **Telegram 메신저 즉시 발송**: 감시 조건에 부합하는 새로운 매물이 등록되면 계약일, 단지명, 층수, 전용면적, 거래금액 정보가 포함된 알림 메시지가 Telegram으로 즉시 발송됩니다.
- **수집 및 알림 이력 관리**: 각 규칙별 최근 검사 일시(`Check-Runs`)와 발송된 알림 히스토리(`Notifications`)를 웹 대시보드에서 투명하게 확인하고 관리할 수 있습니다.
- **수동 즉시 검사**: 주기적 스케줄링 외에도 대시보드에서 "즉시 실행" 버튼을 눌러 신규 매물 등록 여부를 바로 확인할 수 있습니다.

### 2. ⚡ 초고속 실거래 검색 & 스마트 동기화
- **지역명 & 단지명 주소 자동완성**: 자연어로 지역명을 입력하면 해당 시군구 및 법정동 후보를 자동으로 검색하여 추천합니다.
- **지능형 하이브리드 캐시**:
  - **과거 데이터 즉시 서빙**: 신고가 완료된 과거 3개월 이전 거래는 로컬 데이터베이스에서 0.05초 내외로 즉시 응답합니다.
  - **최신 3개월 실시간 동기화**: 30일 실거래가 신고 유예 기간을 고려하여 최근 3개월 데이터는 실시간 외부 API 조회를 통해 신규 등록 건을 빠짐없이 갱신합니다.
- **단지별 자동 일괄 적재**: 특정 단지 검색 시 해당 지역구(5자리 시군구) 전체 실거래 데이터를 백그라운드에서 안전하게 적재하여 이후 동일 지역 조회의 응답 속도를 극대화합니다.

### 3. 📊 다차원 시각화 분석 대시보드
- **시계열 가격 및 거래량 추이**: 월별 평균 거래가, 최고/최저가, 중위값(Median) 및 거래량 변화를 부드러운 시계열 차트로 직관적으로 확인할 수 있습니다.
- **Box Plot (상자 수염 그림) 통계**: 평형대별 및 층수별 가격 분포(최소값, Q1, 중앙값, Q3, 최대값)를 시각화하여 이상치 거래와 주요 거래 가격대를 한눈에 파악합니다.
- **단지별 종합 리포트**: 단지 기본 정보(세대수, 주차공간, 준공연월), 최근 10건 실거래 목록, 평형별/층수별 가격 매트릭스를 제공합니다.
- **단위 원클릭 변환**:
  - 전용면적(실평수) ↔ 공급면적(분양평수) 간 전환
  - ㎡(제곱미터) ↔ 평(3.3㎡) 단위 간 즉각 토글

### 4. 🤖 AI 실거래 인사이트 (Gemini AI)
- **시장 동향 자동 분석**: 수집된 최근 거래 데이터와 가격 흐름을 바탕으로 Gemini LLM이 단지의 시세 추세와 최근 거래 특징을 종합 요약합니다.
- **의사결정 참고 인사이트**: 단순 수치 확인을 넘어 최근 급등/급락 여부, 거래량 회복세, 매수·매도 타이밍 검토에 유용한 정성적 분석 코멘트를 제공합니다.

### 5. 🚇 지하철역 역세권 분석 (Nearby Station)
- **반경별 역세권 단지 탐색**: 지하철역 검색 시 도보 접근 반경(300m, 500m, 1,000m) 내 위치한 아파트 단지를 카카오 지도 위에 한눈에 매핑합니다.
- **수집 현황 표시 & 즉시 수집 요청**: DB 수집 완료 단지와 미수집 단지를 시각적으로 구분하며, 미수집 단지는 "실거래 수집" 버튼 클릭 한 번으로 즉시 데이터를 적재할 수 있습니다.

### 6. 🗺️ 지역별 아파트 지도 탐색 (Region Map)
- **시군구 단지 클러스터 및 평단가 히트맵**: 지역 내 전체 단지의 지리적 위치, 최신 거래가, 평균 3.3㎡당 가격(평단가), 거래량을 지도 마커와 리스트 카드로 동시에 탐색할 수 있습니다.
- **원클릭 상세 분석 연동**: 지도 마커나 단지 카드를 클릭하면 단지별 정밀 분석 페이지로 바로 이동합니다.

### 7. 📈 수집 통계 & 데이터 관리 콘솔
- **수집 현황 드릴다운 (`Collect Page`)**: 날짜별/월별 실거래 수집 건수 및 평균 평단가 추이를 확인하고, 특정 일자를 클릭하여 지역별 수집 상세 내역을 세부 검토할 수 있습니다.
- **위치 좌표 시각 보정 도구 (`CoordPickerMap`)**: 위치 좌표가 누락되었거나 주소 매핑이 불완전한 단지를 카카오 지도 위에서 직접 클릭하여 보정할 수 있습니다.
- **일괄 지오코딩 관리**: 미매핑 단지의 위경도 좌표를 백그라운드에서 일괄 매핑하고 실패 이력을 점검할 수 있습니다.

### 8. 🎨 사용자 맞춤 테마 & 다국어 지원 (i18n)
- **테마 커스터마이징**: WDS Blue, Violet, Green 액센트 컬러와 다크 모드/라이트 모드를 지원합니다.
- **타이포그래피 설정**: Noto Sans KR / Noto Serif KR 서체 선택 및 글자 크기(12px~22px) 실시간 조절 슬라이더를 제공합니다.
- **완벽한 다국어 지원**: 모든 화면 텍스트가 한국어 및 영어를 지원하며 헤더/설정 메뉴에서 즉시 전환할 수 있습니다.
- **반응형 모바일 퍼스트 레이아웃**: 390px 스마트폰 화면부터 태블릿, 와이드 데스크톱까지 단절 없는 사용 경험을 보장합니다.

### 9. 🔐 안전한 사용자 인증 & 개인화 설정
- **Google OAuth 2.0 로그인**: 비인가 사용자의 접근을 안전하게 차단하고 보안 세션을 유지합니다.
- **접근 허용 이메일 화이트리스트**: 등록된 사용자 및 관리자만 시스템에 접근할 수 있도록 보안을 유지합니다.
- **개인별 알림 및 API 키 분리**: Telegram 봇 토큰, 카카오 API 키, Gemini API 키를 사용자 계정별로 독립적으로 관리하여 사용할 수 있습니다.
